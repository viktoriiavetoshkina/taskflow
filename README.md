# TaskFlow

TaskFlow is a full-stack project management
application designed to help individuals
and teams organize their work.

## Planned Features

- User authentication
- Workspaces and projects
- Task management
- Team collaboration
- Role-based access control
- Dashboard and activity tracking

## Tech Stack

- React
- TypeScript
- Node.js
- Express
- PostgreSQL

## Project Status

Currently in development.

## Learning Objectives

- Practice full-stack development.
- Build REST APIs.
- Work with relational databases.
- Improve Git and GitHub skills.
- Learn testing and deployment.
